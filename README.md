# 極・炒飯道 (Goku Chahan-dou)
### 〜 職人の鍋振りと火力を極める体感型中華鍋アクションゲーム 〜

スマートフォンやタブレットの画面を上向きに持ち、手首のスナップで端末を振ることで、実際の中華鍋の「煽り（鍋振り）」とダイレクトに連動する体感型アクションゲームです。

米ジョージア工科大学による「チャーハンの物理学（約3Hzの楕円煽り運動）」研究をベースにした本格的な挙動シミュレーションと、町中華の黄金手順を融合させています。

---

## 🎮 ゲームの特徴

1. **実機センサー連動の本格鍋あおり（Toss）**
   * スマホを手前に引き込み（-Y）、手首を返して跳ね上げる（+Z）コンビネーション動作を低遅延検出。
   * プロの黄金リズム（約0.3秒間隔 / 3Hz）をキープすることで「PERFECT RHYTHM」が発動し、米が一気にパラパラに！
2. **米粒800粒＋具材の超高速物理シミュレーション**
   * GPU Instancing により、スマホでも高フレームレート（60〜120fps）を維持。
   * 中華鍋の放物面ボウル（$y = a(x^2 + z^2)$）による数学的衝突判定。
   * 米粒は白米 ➔ 卵コーティング ➔ 黄金色 ➔ 焦げ茶色へとリアルタイムにシェーダーでグラデーション変化。
3. **具材投入のタイミング勝負**
   * **溶き卵 ➔ ご飯：** 1.5〜3秒以内の半熟状態でご飯を投入し「黄金コーティング」成功。
   * **長ネギ：** 終了10秒前以内の終盤投入で「シャキシャキネギ」ボーナス。
   * **鍋肌醤油：** 終盤に熱々の鍋肌へ回し入れることで「**鑊気（WOK HEI）**」が覚醒！
4. **フィニッシュの「パカッ！」反転皿盛り**
   * 「お玉まとめ」でお玉の中心に米粒を集約。
   * スマホを下向きに180度ひっくり返す（パカッ！）とお皿にドーム型チャーハンが盛り付けられます。
5. **プロシージャル効果音**
   * 金属の煽り音、強火のジュージュー音、醤油のジュワァッ！、皿盛りのパカッ音などを搭載。

## 🛠 動作環境・開発スタック

* **ゲームエンジン:** Unity 6 (6000.3.10f1 Apple silicon / Windows)
* **開発言語:** C#
* **対応プラットフォーム:** iOS / Android (エディタ・PCでのキーボードテストにも対応)
* **Webプロトタイプ:** HTML5 Canvas + Web Audio API + DeviceMotion (ディレクトリ `web-prototype/` に同梱)

## 🕹 操作方法

### Unityエディタ（PCテスト）
* **具材ボタン:** 画面上のボタンをクリック
* **[Space] キー:** 鍋あおり（煽り）
* **[F] キー:** 皿盛り（パカッと反転）

### スマートフォン・タブレット実機
1. 画面を天井（上向き）に向けて持ちます。
2. 手首をクイッと手前にあおると米が舞います。
3. 最後に「お玉まとめ」を押し、端末を画面下向きにパカッと裏返してお皿に盛り付けます。
